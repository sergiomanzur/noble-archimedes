Noble Archimedes Beta 0.9.5b for Windows x64
============================================

Extract this ZIP to a writable folder and run NobleArchimedesLauncher.exe.
Supply your original USA Xbox disc image or extracted game files in assets.
For extracted files, keep default.xbe and the original folder layout.
The included compiler builds the game DLL locally on first run. This can
take several minutes. Keep the compiler folder alongside the launcher.

F10 opens the in-game Graphics and Controls settings. F5 cycles camera
modes and F6 toggles mouse capture. See the changelog for camera, save
loading and graphics changes. The Windows build requires Direct3D 12.
Optional NVIDIA features require compatible hardware and a separately
installed Streamline runtime. The Windows ZIP includes the runtime's
open-source renderer and project artwork and music.

To carry saves forward, copy the hdd folder from your previous build while
both builds are closed. Keep a backup of that folder.

The companion source archive contains the corresponding project, patched
SDK, and donor and build dependency sources. The manifest records the
source pins and file hashes. See the licenses folder and compiler's LLVM
license for redistribution terms and credits.
